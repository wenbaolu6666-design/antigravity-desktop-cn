# 反重力中文汉化插件规则

- 当会话上下文中出现 `【汉化守护】` 开头的系统消息时，用一句简体中文告知用户，不要重复播报，也不要展开成教程。
- 用户要求“安装汉化 / 修复中文 / 更新后又变英文 / 还原英文 / 查看汉化状态”时，使用 `antigravity-zh-cn` 技能。
- 不要直接编辑 `app.asar`、注册表或计划任务；所有安装、修复、还原操作都通过仓库中的 `installer\*.ps1` 完成。
- 不要声称插件本身能改写宿主界面：Antigravity 插件只能提供技能、规则和侧边栏面板；宿主界面汉化依赖 ASAR 补丁与客户端重启。
- 安装或修复前提醒用户保存工作，因为安装器会关闭并重启 Antigravity。
